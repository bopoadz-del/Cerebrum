## Bug Fix: /cost Command [2026-04-04 18:39]

### Problem
`/cost concrete` returned "Resource not found" (404 error)

### Root Cause
Frontend was calling wrong endpoint:
- ❌ `/economics/search` (404)
- ✅ `/economics/rsmeans/search` (correct)

### Fix
Changed URL in `useChat.ts` handleCostCommand function

### Commit
`09b6e31` - "fix: Correct economics endpoint path for /cost command"

### Verification
✅ `/cost concrete` now returns RSMeans data:
- Ready-mix concrete, 3000 psi — $135/CY
- Ready-mix concrete, 4000 psi — $152/CY
- Concrete finishing options

### Problem
Users got "Network error. Please check your connection" when uploading files from mobile.

### Root Causes
1. **CORS preflight** not handling mobile browsers properly
2. **Poor error logging** masked the real problem
3. **Missing mobile optimizations** (timeout, error handling)

### Fixes Applied
- **Backend**: Explicit OPTIONS handler for CORS preflight
- **Backend**: Fixed CORS config for mobile (explicit methods, all headers)
- **Frontend**: Enhanced error messages (CORS, auth, file size)
- **Frontend**: Added 2-minute timeout for slow mobile connections
- **Frontend**: Better logging for debugging
