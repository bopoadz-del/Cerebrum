NEW API ENDPOINTS
================================================================================

CHAT ENDPOINTS:
---------------
POST   /api/v1/chat/completions          - Enhanced chat with web search, code exec
POST   /api/v1/chat/completions/stream   - Streaming chat (SSE)
POST   /api/v1/chat/execute-code         - Execute Python code safely
POST   /api/v1/chat/analyze-code         - Analyze code without executing
POST   /api/v1/chat/analyze-image        - Analyze uploaded image
POST   /api/v1/chat/analyze-image/base64 - Analyze base64 image
POST   /api/v1/chat/web-search           - Explicit web search
GET    /api/v1/chat/models               - List available models
GET    /api/v1/chat/capabilities         - Get chat capabilities
GET    /api/v1/chat/health               - Health check

DOCUMENT ENDPOINTS:
-------------------
POST   /api/v1/documents/analyze         - AI document analysis
POST   /api/v1/documents/analyze/file    - Upload and analyze document
POST   /api/v1/documents/summarize       - Quick summarization
POST   /api/v1/documents/extract-keywords - Extract keywords
